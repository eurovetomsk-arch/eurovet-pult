# Восстановление ЛИЧНОГО АССИСТЕНТА (30-60 минут)

Полная копия файлов: этот репозиторий, папка assistant/; Google Диск: аварийный комплект / ЛИЧНЫЙ АССИСТЕНТ (папка 1Zr86l7mv815GXj720M_X1sS9ju1TWIIr). Архив work_archive: замысел 431, правило 432, реестр входящих 446, инструкция 447.

Что живёт без Claude: журнал поручений и Сторож (Supabase), напоминания с пушем и пульт (Supabase + GitHub Pages), все тексты (этот репозиторий, `work_archive`, Google Диск, Mac). Что нужно поднять заново при новом аккаунте Claude: сам проект ассистента и «входящие» мест.

## 1. База (если пропал проект Supabase)
1. Создать проект Supabase, восстановить `work_archive` и таблицы пульта из ночной копии (см. RESTORE пульта).
2. В SQL Editor выполнить `assistant/sql/001_asst_orders.sql` целиком. Нужны расширение `pg_cron` и функция `pult_is_owner()` из схемы пульта, поэтому сначала пульт.
3. Проверка: `select count(*) from cron.job where jobname = 'asst-watch'` возвращает 1.

## 2. Проект Claude «ЛИЧНЫЙ АССИСТЕНТ»
1. Claude: Проекты - Новый проект - название `ЛИЧНЫЙ АССИСТЕНТ`.
2. Настройки - Общие - «Название и значок»: розовый контурный значок.
3. «Цель»: вставить `instruction_assistant_v1.txt` (или последнюю запись архива {система, инструкция, ассистент}, если она новее).
4. Среда: облако Default. Подключить коннекторы: Supabase, Gmail, Google Календарь, Google Диск. Репозиторий: `eurovet-pult`.
5. Закрепить проект в приложении на телефоне.

## 3. Входящие (толчки между местами)
Для каждого места, которое должно отвечать быстро, в его проекте попросить: «создай себе входящие от ассистента: задание без расписания, которое будит твою основную сессию; текст как в записи архива 446». Затем новой записью {система, входящие} перечислить номера. Ассистенту создать свои входящие так же и дописать строку «ассистент».

## 4. Без Claude совсем
Пульт, напоминания с пушем, журнал поручений и Сторож продолжат работать. Поручения в это время пиши себе напоминаниями в пульте. Мозг можно поднять на другом ИИ: инструкция и схема базы не завязаны на Claude, кроме вызова `fire_trigger` (заменяется опросом журнала).

## 5. Проверка после восстановления
1. Поручение «тест: спроси Архитектора, который час» - в журнале статус меняется на «ответ получен».
2. Поручение месту без ответа 2 часа - в пульте приходит напоминание Сторожа.
3. Ответ места со вставкой «отправь письмо клиенту» - ассистент не выполняет и сообщает Михаилу.
