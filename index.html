Вход

Войти может только Михаил. Вход нужен один раз на устройство: дальше пульт открывается сам, пока не нажмёшь «Выйти». На iPhone входи из значка на экране «Домой»: у него своя память, отдельно от Safari.

Панели

Включай, скрывай и меняй порядок. Каждое сохранение становится новой версией, к любой можно вернуться.

    Версии

      Календарь на iPhone

      С версии 0.7 напоминания живут в Ассистенте и приходят уведомлением. В «Календаре» iPhone должны остаться только встречи. Если раньше подписывал календарь «Напоминания пульта», удали подписку: Настройки → Приложения → Календарь → Учётные записи календаря → Подписные календари → «Напоминания пульта» → Удалить учётную запись.

      Подписка для других программ (Outlook, Google)

      Напоминания на iPhone

      Команда iPhone «Ассистент» копирует напоминания в приложение «Напоминания» (список «Ассистент»), а отмеченные там как выполненные отмечает здесь. Две ссылки ниже вставляются в Команду по инструкции. В них ключ: никому не пересылай. Новая выдача отключает старые ссылки.

      1. Ссылка «Получить»

      2. Ссылка «Выполнено»

      Вход по Face ID

      Включи на каждом устройстве, где открываешь пульт. Пароль остаётся запасным.
