## 3. Поднять с нуля на новом Supabase (30-60 минут, без программиста)

1. supabase.com - New project, бесплатный тариф, регион Europe. Запишите адрес проекта (вида `abcd1234.supabase.co`).
2. SQL Editor - New query - вставить весь файл `02_схема_базы.sql`. В разделе 10 файла заменить `ikxmzapfmgqnnrsttuxc` на код нового проекта. Run. Должно пройти без красных ошибок (если нет таблицы work_archive, это нормально: та строка закомментирована).
3. Edge Functions - Deploy new function, четыре штуки, код из папки `supabase/functions/` в архиве кода:
   - `pult-calendar` (Verify JWT: включено)
   - `pult-push`, `pult-passkey`, `pult-export` (Verify JWT: выключено, они проверяют доступ сами)
4. Если адрес сайта пульта меняется, в `pult-passkey/index.ts` поправить `CFG` (адрес сайта).
5. Edge Functions - Secrets: `PULT_ICAL_URL` = секретный адрес iCal (Google Календарь - Настройки - ваш календарь - «Секретный адрес в формате iCal»).
6. В файле `app.js` в начале заменить `CFG.url` на адрес нового проекта и `CFG.key` на Publishable key (Project Settings - API Keys). Залить файлы на хостинг.
7. Открыть пульт, «Создать вход (один раз)» с почтой vitatiba101010@gmail.com. Если просит подтвердить почту: SQL Editor
   `update auth.users set email_confirmed_at = now() where email = 'vitatiba101010@gmail.com';`
8. Вернуть данные: SQL Editor - вставить `03_вернуть_данные.sql`, слово `ВСТАВЬТЕ_ДАННЫЕ_ЗДЕСЬ` заменить содержимым последнего `pult_ДАТА.json` - Run. Внизу появится «Готово: дел N из N...». Повторный запуск ничего не портит.
9. В пульте: «Включить уведомления», «Включить Face ID», и заново подписать календарь iPhone (новая ссылка, `04_запасной_режим.md`).
10. Занести в новую базу отпечаток токена Mac (раздел 4): он показан в журнале установки, или запустите `install.sh` ещё раз, он выведет его снова.

Проверка, что всё живо: в SQL Editor `select jobname, status, start_time from cron.job_run_details order by start_time desc limit 5;` - строки `pult-push-tick` со статусом succeeded каждые 5 минут.

## 4. Копия на Mac (без ИИ)

Mac каждый день в 04:15 (и при включении) сам скачивает данные и напоминания, по воскресеньям код. Делает это программа macOS (launchd) скриптом `mac/eurovet-recovery.sh`, Claude не участвует. Журнал: `Desktop/work/ВОССТАНОВЛЕНИЕ/журнал.txt`.

Доступ Mac к копии: свой токен лежит только на Mac в `~/.eurovet/export_token`, в базе хранится лишь его отпечаток (строка `export_hash:mac` в `pult_private`). Токен Mac не проходит через чат и ИИ.

**Копия на Mac не обновляется** (появился файл `ВНИМАНИЕ_копия_не_обновилась.txt`): посмотреть последнюю строку журнала.
- «не скачались»: нет интернета или упал Supabase (раздел 2), либо после переезда базы в ней нет отпечатка Mac (ниже).
- Переустановка или новый Mac: в Терминале под пользователем agent `bash ~/Desktop/work/ВОССТАНОВЛЕНИЕ/mac/install.sh`. Пароль администратора не нужен. Скрипт покажет «Отпечаток токена». Занести его в базу: SQL Editor
  `insert into public.pult_private(key, value) values ('export_hash:mac', 'ОТПЕЧАТОК') on conflict (key) do update set value = excluded.value;`
- Отозвать доступ Mac: тот же запрос с любым словом вместо отпечатка, например `'отозван'`.

## 5. Что где в этой папке

- `00_ЧИТАЙ_МЕНЯ.md` - этот файл.
- `01_ПРОМПТ_ДЛЯ_ЛЮБОГО_ИИ.md` - отдать любому ИИ (ChatGPT, Gemini, GigaChat, YandexGPT, Claude), чтобы он восстановил или продолжил систему.

- `03_вернуть_данные.sql` - вернуть данные из JSON-копии.
- `04_запасной_режим.md` - напоминания в календаре iPhone и Google без пульта и без ИИ; ссылки выгрузки.
- `mac/` - скрипт ежедневной копии на Mac и установка.
- `данные/` (только на Mac, Диске и ПК, не на GitHub) - JSON и ICS по датам.
- `код/` (только на Mac) - архивы кода по неделям.
- В корне репозитория: `RESTORE.md` (короткая версия раздела 3), `supabase/migrations/` (история изменений базы), `supabase/functions/` (код функций).
