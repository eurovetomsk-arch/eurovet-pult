# Как поднять пульт с нуля

Пульт не зависит от Claude: экран живёт на GitHub Pages, данные, календарь, напоминания и уведомления в Supabase.
От Claude зависят только счётчики почты (агент снимка, архив 430) и ярлыки почты, по которым они считаются.

## Что где лежит

| Часть | Где | Копия |
|---|---|---|
| Код экрана и функций | этот репозиторий, ветка `main` (рабочая `v0`) | Google Диск и Mac, раз в неделю |
| Схема базы | `supabase/migrations/*.sql` | там же |
| Данные (напоминания, панели) | Supabase, таблицы `pult_*` | ночная копия `pult_backup` (31 ячейка по числу месяца), раз в неделю JSON на Диск и Mac |
| Ссылка календаря iCal | секрет `PULT_ICAL_URL` в Supabase | у Михаила в Google Календаре, сбрасывается там же |
| Ключи уведомлений | `pult_private`, создаются автоматически | не нужны: при переезде создадутся заново, уведомления включить ещё раз |

## Переезд на новый проект Supabase (30-60 минут)

1. supabase.com: новый проект (бесплатный тариф), регион Europe.
2. SQL Editor: выполнить по очереди все файлы из `supabase/migrations/` по возрастанию имени.
   В файле `*_push_cron.sql` заменить адрес `ikxmzapfmgqnnrsttuxc` на адрес нового проекта.
   В файле `*_schema.sql` проверить почту владельца в `pult_settings`.
3. Edge Functions: создать `pult-calendar` (проверка JWT включена), `pult-push` и `pult-passkey` (проверка JWT выключена), код из `supabase/functions/`.
   Если меняется адрес пульта (не eurovetomsk-arch.github.io), поправить `CFG` в `pult-passkey/index.ts` и заново включить Face ID на устройствах.
4. Edge Functions - Secrets: `PULT_ICAL_URL` = секретный адрес iCal из Google Календаря (Настройки - календарь - «Секретный адрес в формате iCal»).
5. В `app.js` заменить `CFG.url` и `CFG.key` на адрес и публичный ключ (Publishable key) нового проекта. Залить в репозиторий.
6. Открыть пульт, «Создать вход (один раз)» с почтой владельца. Если вход просит подтверждение: в SQL Editor
   `update auth.users set email_confirmed_at = now() where email = '<почта>';`
7. Вернуть данные: последняя JSON-копия - вставить задачи в `pult_tasks` (owner_id = новый id владельца) и последнюю версию `layout` в `pult_layout`.
8. В пульте: «Включить уведомления» и «Включить Face ID» (Панели).

## Переезд репозитория или потеря GitHub

Любой статический хостинг подойдёт (Cloudflare Pages, Netlify): файлы `index.html`, `app.js`, `sw.js`, `manifest.webmanifest`, иконки, папка `vendor/`. Сборка не нужна.

## Если пропал аккаунт Claude

Пульт продолжает работать: вход, напоминания, уведомления, календарь. Почта покажет красную плашку «данные устарели».
Чтобы вернуть счётчики: в новом аккаунте создать плановую задачу с текстом из архива 430 (каждый час 07-22 по Омску), подключив Gmail и Supabase.

## Безопасность

- Вход только по почте владельца, регистрация других адресов закрыта триггером в базе.
- Вход по Face ID: ключ passkey в связке ключей iCloud, в базе только его открытая часть (`pult_passkeys`); после проверки функция выдаёт одноразовый токен входа владельца.
- Все таблицы `pult_*` закрыты RLS: читает и пишет только владелец.
- В базе нет писем, тем, отправителей и данных клиентов: от почты только 4 числа.
- Секреты (iCal, ключи уведомлений, токен таймера) не лежат ни в репозитории, ни в архиве.
